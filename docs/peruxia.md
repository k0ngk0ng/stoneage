# 佩露夏

当前 Web 支持原始数据中的佩露夏，复用 2.5 服务端模板和现有动画，不修改成长或技能规则。

佩露夏只通过管理端赠送。管理后台进入玩家详情，选择背包或宠物仓库，点击赠送宠物，搜索“佩露夏”并选择模板 `777`；游戏内不增加商店、任务奖励或野外捕捉入口。

| 用途 | 编号 |
|---|---|
| 管理后台发放的宠物模板 | `777` |
| 旧服务端生成记录 | `1610`（等级 1） |
| 地图、宠物面板及战斗动画 | `100872` |
| 12 种人物的骑乘动画 | `104025`–`104036` |
| 图鉴照片逻辑编号 | `28196` |
| 图鉴照片物理图片 | `bitmaps/bitmap_126325.png` |

`enemybase.txt` 模板 777 的初始点数为 30，升级点数参数为 4.50，体力、腕力、耐力、速度的基准参数为 30/44/20/29，水属性 100，默认技能为攻击和防御，最多 7 个技能槽。这些模板参数不等于直接显示的一级血攻防敏。原始等级限制字段为 28；本次保留原始规则。其他同名模板及“凶猛的佩露夏”属于不同配置，发放时应选择模板 777。

管理端赠送后，白虎沿用当前 2.5 的骑乘资格检查，包括骑乘等级、宠物等级、忠诚度及转生限制，不额外要求白虎骑证。服务端按人物族型选择骑乘造型；获得方式仍只有管理端赠送。

骑乘资源来自保留的新养老客户端 `path/ride-3-1.82-110000-110105/`，源动画 `110048`–`110059` 对应上述 12 种人物，共 3072 张图片。原始 ADRN 已按配套客户端读取流程解码，并逐条与 REAL 图片头校验；导入保留原始绘制偏移、动作时序和攻击事件。图片固定使用 `bitmaps/white-tiger-8.5/` 路径，来源校验值见资源包的 `white-tiger-ride-provenance.json`。

`scripts/import-white-tiger-assets.py` 可使用长期保留的 BIN 和同组 `adrn.decoded.bin` 重新生成独立骑乘资源包。全量重建 2.5 素材时，需要同时合入该包的图片，以及 `sprites.json`、`field-bootstrap-sprites.json` 中的白虎条目。发布前须同步 OSS 图片和这两份清单，并核验资源版本标记。

图鉴扩展声明在 `client/web/album-extensions.json`。佩露夏追加在原有 224 条之后，显示为 No.225，不改变旧图鉴的位置或本地收藏。客户端收到佩露夏的宠物状态后解锁图鉴，使用动画到照片的明确映射，并保存实际宠物数值。

已有完整资源包时可增量更新图鉴：

```sh
python3 -B tools/extract-legacy-web-assets.py --album-only
node client/web/album_test.js
python3 -B tools/extract-legacy-web-assets_test.py
```

该命令读取仓库保留的原始客户端数据，仅刷新图鉴和照片。完整资源导出也包含这一扩展。程序发布时还需按现有资源发布流程同步更新后的 `manifest.json` 和 `bitmap_126325.png`；已有动画和旧图片保持复用，CDN 使用固定路径。
