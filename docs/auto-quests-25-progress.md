# 2.5 自动任务实现进度

目标是完整支持 2.5 及其包含的 1.82、2.0 任务的自动完成，包含前置任务、分支、交付、战斗、采集/捕宠/制作、异常恢复和结果核验。不能以任务名称出现在菜单或攻略已收录作为完成标准。

## v0.2.18 发布收尾与暂停交接（2026-10-03）

用户要求先发布当前一版，再暂停。以下实现状态作为恢复工作的起点，不能将发版等同于全部任务完成。发布是否完成以对应 GitHub Release 和部署验收记录为准；原始测试证据保留在 `build/quests-20261003/`。

- 目标仍是百科 97 条任务（含 48 个委托）及骑乘。已有 11 个定义，只有玛丽娜丝宠物委托 A 完成正式 HTTP/sactl/原版服务全链路验收；其余保持未验证，不扩大生产自动任务配置。
- 新修复：`item use <slot>` 默认目标由非法 -1 改为原版自身 0，并拒绝多余参数、越界目标及 32 位整数溢出；HTTP 观察在已结束 PvE 发送 EO 后回到 world；自动战斗显示对话框等阻塞原因；补给等待窗口时不再把上次已提交的商店菜单当作新回复。
- 遇敌导航改为搜索实际可达且生效的目标格，遵守原版重叠行优先级；保持等级、生命和时间限制。静态导航回归通过不意味着低等级自然练级全部可用。
- 最新卡鲁它那真实验收 `karutana-fresh-shop-native.log`：普通一级新角色经正常买肉、关闭商店、野外自动战斗升到二级并回血，预检通过，完成委托书和补给购买（2/7）；随后采集途中死亡，任务暂停。证据 `http-commission-295422330/plans.db`，任务 `task-28edfb4d3850a92fda111c346f5669cf`。不能晋升该草稿，不能把失败重写为成功。
- 恢复后先核查这次死亡前的路线、遭遇、恢复阈值与捕宠动作，再做隔离验收；不要放松安全限制、注入等级/属性或绕过审核。萨姆吉尔、加加仍未完整验收；一级自然练级寻路与 CLI 命名 talk 的柜台两格交互差距也仍待处理。
- 四包回归 `item-self-battle-regression.log`、三包回归 `item-shop-final-regression.log`、商店延迟窗口回归 `stock-window-regression.log` 均通过。发布测试及 CDN/生产验收另存 `build/release-v0.2.18/`。
- 本地 learned 权重未更改。已有修复覆盖合击/不服从战报、回合编号及候选模型状态显示；不代表训练效果改善。原始模型、训练数据和线上单场证据保持原样。

- 百科任务来源 `internal/gamewiki/quests.json` 有 97 个条目，包含 48 个村庄宠物/食物委托和各任务分支。完整跟踪表见 [auto-quests-25-scope.json](auto-quests-25-scope.json)。骑乘教学另行纳入，不能因不在百科这 97 条中而遗漏。
- 自动任务定义现在有 11 个：已验证的玛丽娜丝村宠物委托 A，以及新增但仍禁用的萨姆吉尔、加加、卡鲁它那宠物委托 A 三份草稿；原有花与贝壳交换的保存点 0 分支、骑乘教学、成人仪式，以及斧头任务的 4 个依赖阶段仍保持 unverified。斧头已完成下面记录的安全模式任务引擎实跑，但正式目录审核、普通角色准备条件及断线恢复验收尚未完成。
- 公共知识加载器新增无扩展名的 ExChangeMan 任务脚本解析。在当前有效数据目录实际读取到 312 个这类文件，其中 308 个可结构化解析，共 1,440 个分支；4 个仍保留明确解析错误。这些数字是脚本解析覆盖量，不是已完成任务数。
- 保留任务分支的原始顺序、逗号 OR / `&` AND 条件分组、道具/宠物交付与奖励原字段、`Break` 等裸标记、重复字段和源码位置/摘要。没有实现对任意原版条件及副作用的模拟，也没有由此自动批准任务执行。
- 原版 `NPC_Util_MargeStrFromArgFile` 调用的 `chompex` 只移除换行，且字段查询使用子串匹配。因此 `#EventNo` 等看似注释掉的控制字段不能直接丢弃；解析结果以 `commented_control` / `commented` 保留，后续执行编译须单独核验。
- 公共 NPC 执行器支持由已核验 NPC 目录指定的固定 `talk_text`（含 `P|` 前缀），用于暗号/猜谜等对话。执行请求不能覆盖目录中的文本；仍核验 NPC 身份、位置、距离、朝向和观察版本。未配置时保持原有 `P|hi`。
- 已新增 `sactl quest list|preview|start|status|pause|resume|cancel`，仅用于已登录的 HTTP 会话，复用 Web 已有执行器、权限和持久化恢复。未增加 Web 界面，未发布或部署。自动练级 CLI 和 TCP 会话任务入口仍有差距。
