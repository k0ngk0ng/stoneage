# 管理端礼包

管理员登录后，从导航的“礼包”进入 `/gifts`。礼包由多种物品和宠物及各自数量组成；数量表示独立物品或宠物个数。此功能只向角色随身背包和宠物栏发放，一份礼包最多包含 15 件物品、5 只宠物。

## 制作与发放

1. 新建礼包，输入名称，按名称或 ID 搜索并添加物品、宠物，调整数量后保存。
2. 选择礼包，指定一个账号下的角色，或选择全部角色。
3. 生成预览，检查目标角色数、可发放数，以及容量不足的角色和原因。
4. 确认发放后，在发放记录中查看每个角色的处理结果。

预览会固定目标名单，包含账号的两个已存在角色槽位；全部角色也包含停用账号下的角色。容量不足时整份礼包跳过该角色。正式发放前再次检查角色身份和容量。预览有效期为 10 分钟，修改礼包内容后需要重新预览。

同一次预览重复确认会返回原有任务，不会创建另一份赠送任务。重新生成预览再确认代表一次新的赠送。

## 结果与中断

关闭管理页面不会取消已提交的任务。任务和各角色的结果保存在认证数据库，并记录审计事件；在线角色通过原生游戏服务修改并保存，离线角色通过存档比较后一次性写入。

“待核实”表示执行或保存结果无法确定，例如管理服务在发送期间重启。系统不会自动重发这类角色；应先在玩家资产页面核对实际物品和宠物，再决定是否另行赠送。重启后尚未开始发送的任务会继续处理。
