sactl 客户端与天梯 AI 指挥官

支持 macOS、Windows、Linux。一键安装客户端，并把游戏操作 skill 安装到 Codex 和 Claude Code 的标准用户目录，无需 Python。

安装后填写游戏地址、账号和角色，再启动 sactl serve。安装不会自动登录，也不会改动 Agent 的配置文件。

终端补全 · v0.2.0

Homebrew、deb/rpm 和下载包现已提供 bash/zsh 补全。shell 已启用补全框架时，包管理器升级后重新打开终端即可使用；也可在当前终端直接加载：

# zsh
autoload -Uz compinit && compinit
source <(sactl completion zsh)
# bash
source <(sactl completion bash)

需要每次打开终端都加载，可把对应语句加入 ~/.zshrc 或 ~/.bashrc。支持命令、arena 子命令、选项和路径补全；补全过程不登录游戏。

天梯 AI 指挥官 · sactl arena

从 v0.1.99 起，天梯 AI 指挥官已整合到 sactl arena，只需安装一个 sactl 客户端，包内附配置示例与使用说明。一支队伍由一个指挥官统一控制，支持 1v1–5v5 自动登录、组队、匹配和作战。连接线上天梯无需 Docker 或 Python。

安装后，在终端创建一支队伍的配置（将 --mode 1 改成 2–5 可创建多人队伍）：

sactl arena init --directory arena-team --mode 1

填写目录内各成员 TOML 的账号、角色，以及对应 password 文件中的密码，然后运行：

sactl arena check --config arena-team/team.json
sactl arena run --config arena-team/team.json --forever

默认「顺序攻击」basic 无需模型或 API Key。可切换为「经验指挥」learned、「推演指挥」llm 或「联合参谋」hybrid；学习策略需要训练模型，大模型策略需要自行配置服务。实验训练器尚不代表高胜率策略。

战斗数据保存在队伍目录内的 data/arena.sqlite3，可继续用于训练与评估。首次 Ctrl-C 在当前比赛结束后停止，再次 Ctrl-C 立即退出。完整说明见安装包内 local-arena-agent.md；本地隔离游戏服的批量模拟采集另需 Docker。

如何导入

  1. 下载完整游戏资源 ZIP，无需解压。
  2. 打开游戏「系统 → 导入资源」，选择下载的 ZIP 文件。
  3. 点击「开始导入」，完成后即可复用本地资源。

导入过程中可取消；重新选择同一个包可继续，已保存的有效文件会跳过。

缓存保存在当前浏览器和网站中。更换浏览器或清除网站数据后，需要重新导入。资源更新后请下载新版资源包；登录与游戏操作仍需联网。
